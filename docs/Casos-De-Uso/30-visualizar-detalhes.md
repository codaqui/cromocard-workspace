| Nome do Caso de Uso | Visualizar Detalhes |
|---|---|
| Finalidade/Objetivo | Permitir que o visitante ou o cliente visualize os detalhes de uma carta para conhecer suas características antes de realizar uma compra. |
| Atores | Visitante, Cliente |
| Pré Condições | Nenhuma: o visitante vê a página inteira. Comprar, favoritar e adicionar à coleção pedem login. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O ator seleciona a carta na busca, no marketplace ou na Home. |  |
|  | 2. O sistema apresenta o perfil da carta: as imagens (frente, verso e detalhe), o preço médio de mercado, o menor anúncio, a quantidade de anúncios ativos, os dados de identificação (Visualizar Informações da Carta), o histórico de preços (Visualizar Histórico de Preços) e a lista de anúncios disponíveis, com vendedor, condição e preço, ordenada pelo menor preço. |
| 3. O ator navega pelas informações apresentadas. |  |
| 4. O ator seleciona "Ver anúncio" em um dos anúncios. |  |
|  | 5. O sistema abre o detalhe do anúncio, de onde parte a compra (Comprar). |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O visitante seleciona "Comprar", "Favoritar" ou "Adicionar à coleção". |  |
|  | 2. O sistema mostra "Entre para continuar", com "Continuar com Google", "Entrar com e-mail e senha" e "Criar conta grátis"; depois do login, o usuário volta para a carta. |
|  | 3. Caso a carta não tenha anúncios ativos, a lista informa que não há anúncios, e o vendedor vê a opção "Anunciar esta carta". |
