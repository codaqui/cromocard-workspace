| Nome do Caso de Uso | Visualizar Quantidade Disponível |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso visualizar a quantidade disponível de uma carta para verificar se existe estoque suficiente antes de realizar uma compra. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar visualizando os detalhes de um anúncio. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa os detalhes do anúncio. |  |
|  | 2. O sistema busca a quantidade disponível da carta no anúncio. |
|  | 3. O sistema exibe a quantidade disponível ao cliente. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso a quantidade seja igual a zero, o sistema informa que a carta está indisponível. |
