| Nome do Caso de Uso | Ordenar por Maior Preço |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso ordenar os anúncios por maior preço para visualizar primeiro as cartas de maior valor. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar visualizando a listagem de cartas ou anúncios. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa a listagem de cartas. |  |
| 2. O cliente seleciona a opção “Ordenar por maior preço”. |  |
|  | 3. O sistema organiza os anúncios em ordem decrescente de preço. |
|  | 4. O sistema atualiza a listagem com os anúncios ordenados. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso não existam anúncios disponíveis, o sistema exibe a mensagem: “Nenhum anúncio disponível para ordenação.” |
