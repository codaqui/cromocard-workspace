| Nome do Caso de Uso | Ordenar por Mais Recentes |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso ordenar os anúncios por mais recentes para visualizar primeiro as cartas adicionadas recentemente à plataforma. |
| Atores | Visitante, Cliente |
| Pré Condições | O ator deve estar no Explorar marketplace ou na lista de anúncios do perfil da carta. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O ator acessa o Explorar marketplace ou o perfil da carta. |  |
| 2. O ator seleciona a opção “Ordenar por mais recentes”. |  |
|  | 3. O sistema organiza os anúncios pela data de publicação, do mais recente para o mais antigo. |
|  | 4. O sistema atualiza a listagem. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso não existam anúncios disponíveis, o sistema mostra "Nenhum anúncio encontrado". |
