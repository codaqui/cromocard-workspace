| Nome do Caso de Uso | Visualizar Pedidos |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso visualizar meus pedidos para acompanhar as compras realizadas na plataforma. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa o Dashboard ou a seção “Meus Pedidos”. |  |
|  | 2. O sistema busca os pedidos relacionados ao cliente. |
|  | 3. O sistema exibe a lista de pedidos e suas informações. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso o cliente ainda não possua pedidos, o sistema exibe a mensagem: “Você ainda não possui pedidos.” |
