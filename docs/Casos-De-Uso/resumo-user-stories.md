# Resumo User Stories

## 1. Painel Público (Home, Login, Cadastro)

| User Story | Narrativa |
|---|---|
| Visualizar Destaques | Como visitante eu quero ver destaques, cartas mais procuradas, categorias e notícias na tela Home. |
| Buscar Global | Como visitante eu quero buscar cartas, usuários e grupos diretamente no painel público. |
| Criar Conta | Como visitante eu quero me cadastrar via e-mail informando tipo de usuário, aceitando termos e confirmando o e-mail. |
| Realizar Login | Como visitante eu quero fazer login com e-mail/senha ou Google, com a opção de lembrar usuário. |
| Central de Ajuda /FAQ | Como visitante eu quero acessar uma página de dúvidas frequentes (FAQ) para entender como o aplicativo gerencia trocas e álbuns antes de criar minha conta. |
| Recuperar Senha | Como visitante eu quero solicitar a recuperação da minha senha caso eu a esqueça. |

## 3. Minha Coleção (Álbuns e Cartas)

| User Story | Narrativa |
|---|---|
| Interagir com o Álbum | Como Cliente preciso marcar cartas da grade do álbum como possuo, faltante ou repetida, alterando quantidades. |
| Ordenar Coleção | Como Cliente preciso poder ordenar minhas cartas visualmente na tela por valor de mercado, data de adição ou ordem alfabética. |
| Buscar Categoria do Álbum | Como Cliente preciso selecionar a categoria por seleções e times do álbum para filtrar figurinhas exatos dentro da minha coleção |
| Resetar Progresso do Álbum | Como Cliente preciso poder limpar todos os dados de um álbum caso decida recomeçar a coleção do zero. |
| Adicionar Carta ao Portfólio | Como Cliente preciso pesquisar e adicionar cartas soltas ao meu portfólio para controle pessoal. |
| Buscar Categoria do Card | Como Cliente preciso pesquisar e visualizar os cards através dos seus elementos específicos para encontrar Card exatos dentro da minha coleção. |
| Acessibilidade | Como Cliente preciso ativar recursos como narrador de tela, modo daltonismo e alto contraste para conseguir navegar, ouvir e visualizar as informações da plataforma com clareza. |
| Escanear Carta ou Código | Como Cliente preciso usar a câmera para escanear a imagem da carta ou código de barras para acelerar a adição no catálogo.** |
| Votar em Solicitação de Catálogo | Como Cliente preciso votar a favor, neutro ou contra uma sugestão de nova categoria para ajudar o administrador a decidir o que entra no catálogo.++ |

## 4. Grupos da Comunidade

| User Story | Narrativa |
|---|---|
| Explorar e Entrar em Grupos | Como Cliente preciso buscar grupos, solicitar entrada ou compartilhar o link de um grupo existente. |
| Denunciar Mensagem no Grupo | Como Cliente preciso poder reportar uma mensagem ofensiva ou spam dentro do grupo para que os administradores a avaliem e excluam. |
| Silenciar Notificações de Grupo | Como Cliente preciso silenciar temporariamente um grupo muito ativo para não receber alertas no celular a todo momento. |
| Pesquisar no Histórico do Grupo | Como Cliente preciso uma barra de busca dentro do grupo para localizar mensagens, links ou cartas enviadas em dias anteriores. |
| Criar e Administrar Grupo | Como Cliente preciso criar um grupo, administrar seus membros e fixar mensagens importantes. |
| Interagir no Chat do Grupo | Como Cliente preciso utilizar o chat de texto do grupo para conversar com outros membros, divulgar as cartas que procuro e combinar informalmente horários e locais para trocas presenciais. |
| Compartilhar Cartas | Como Cliente precio compartilhar cartas no grupo para apresentar itens na minha coleção aos participantes.** |
| Compartilhar Imagens | Como Cliente preciso compartilhar imagens no grupo para enviar conteudos.** |

## 5. Chat Pessoal (Conversas)

| User Story | Narrativa |
|---|---|
| Responder Mensagem Específica | Como Cliente preciso poder dar "reply" diretamente em uma mensagem antiga no chat para manter o contexto da conversa. |
| Visualizar Mensagens | Como Cliente preciso visualizar minhas mensagens para acompanhar as conversas realizadas com outros usuários dentro do grupo. |
| Moderar Contatos Privados | Como Cliente preciso ter a opção de bloquear ou denunciar usuários com comportamento inadequado no chat. |

| Conversar com Colecionador | Como Cliente preciso conversar com outros colecionadores de forma privada via chat para alinhar trocas.** |
| Enviar Anexos e Localização | Como Cliente preciso enviar imagens, compartilhar minhas cartas e mandar minha localização no chat.** |

## 6. Perfil e Configurações

| User Story | Narrativa |
|---|---|
| Editar Dados do Perfil | Como Cliente preciso editar minhas informações, alterar minha foto (avatar) e gerenciar meus endereços cadastrados. |
| Exibir Vitrine de Conquistas | Como Cliente preciso que as medalhas/badges que eu ganhei (ex: "Colecionador Veterano") fiquem em destaque na página pública do meu perfil. |
| Denunciar Perfil | Como Cliente preciso poder reportar um perfil inteiro no aplicativo caso suspeite que seja um bot ou golpista. |
| Configurar Privacidade e Senha | Como Cliente preciso alterar minha senha e configurar as opções de privacidade do meu portfólio (público/privado). |
| Exclusão da Conta | Como Cliente preciso poder solicitar a exclusão definitiva da minha conta e dados da plataforma. |
| Compartilhar Conquista Externa | Como Cliente preciso um botão para compartilhar uma nova conquista alcançada (ex: "Álbum Completo!") diretamente nos meus stories do Instagram ou WhatsApp.** |
| Gerenciar Plano PRO | Como Cliente preciso acessar minhas configurações para assinar planos e cadastrar métodos de pagamento da assinatura premium.** |

## 7. Notificações e Favoritos

| User Story | Narrativa |
|---|---|
| Visualizar Notificações | Como Cliente preciso ser notificado sobre novas mensagens, convites para grupos e atualizações da plataforma. |
| Limpar Central de Notificações | Como Cliente preciso um botão de "Marcar todas como lidas" para zerar rapidamente o contador de avisos do sistema. |
| Favoritar Álbum | Como Cliente preciso favoritar álbuns para acessá-los rapidamente posteriormente. |
| Favoritar Carta | Como Cliente preciso favoritar uma carta para acessá-la posteriormente com facilidade. |
| Favoritar Grupo | Como Cliente preciso favoritar um grupo para acessá-la posteriormente com facilidade. |
| Configurar Alertas de Preço | Como Cliente preciso configurar alertas para receber uma notificação push no celular imediatamente quando um item da minha lista de favoritos baixar de preço no mercado agregado.** |

## 8. BackOffice (Administração)

| User Story | Narrativa |
|---|---|
| Visualizar Dashboard Gerencial | Como Administrador eu quero visualizar KPIs (total de usuários, cartas cadastradas, novos cadastros), relatórios no painel e cadastros dos vendedores. |
| Gestão de Usuários | Como Administrador eu quero criar, editar, suspender, excluir e alterar permissões de acesso de qualquer usuário da plataforma. |
| Disparar Notificação Global | Como Administrador eu quero ter um painel para criar e disparar notificações push em massa para a base inteira de usuários informando novidades. |
| Gestão de Catálogo | Como Administrador eu quero cadastrar, editar, excluir ou importar em lote (CSV) as cartas e álbuns do sistema global. |
| Gestão de Comunidade (Grupos) | Como Administrador eu quero poder excluir, suspender grupos e moderar mensagens denunciadas na plataforma. |
| Exportar Relatórios Gerenciais | Como Administrador eu quero exportar os gráficos e tabelas da Dashboard (ex: novos cadastros do mês) para um arquivo CSV ou PDF. |
| Aprovar Solicitações | Como Administrador eu quero analisar e aprovar sugestões de novas cartas, álbuns e categorias feitas pelos usuários. |
| Log de Auditoria Administrativa | Como Administrador eu quero ver um log do sistema registrando qual moderador apagou um grupo ou baniu um usuário para ter controle de segurança das ações da minha equipe. |
| Configurações Globais | Como Administrador eu quero configurar o banner da Home, categorias padrão e templates de notificações da plataforma. |
| Validar Cadastro de Vendedor | Como Administrador eu quero analisar os dados e os documentos de um vendedor e aprovar ou reprovar o credenciamento dele para que só lojistas verificados vendam na plataforma.++ |
| Notificar Pendência Cadastral | Como Administrador eu quero avisar um vendedor, no site e por e-mail, sobre uma pendência no cadastro e o prazo para regularizar para que ele corrija os dados sem precisar recomeçar.++ |
| Acompanhar Evolução de Cadastros | Como Administrador eu quero ver no Dashboard um gráfico dos novos cadastros de colecionadores e de lojistas certificados por período, comparado com a meta mensal, para acompanhar o crescimento da plataforma.++ |
| Visualizar Indicadores Financeiros | Como Administrador eu quero ver no Dashboard o valor em custódia, o valor liquidado no dia e o valor retido em garantia para acompanhar o dinheiro que passa pelo marketplace.++ |
| Gerenciar Dados Complementares do Usuário | Como Administrador eu quero registrar e buscar usuários por nome de usuário (@), telefone e CPF e ver o último acesso de cada um para identificar a conta com rapidez.++ |
| Aplicar Sanção a Usuário | Como Administrador eu quero advertir, suspender por um prazo ou banir definitivamente um usuário, com justificativa, para punir quem descumpre as regras na medida da infração.++ |
| Agendar Notificação Global | Como Administrador eu quero agendar uma notificação global para uma data e hora futuras para comunicar novidades no momento certo.++ |
| Segmentar Notificação Global | Como Administrador eu quero enviar uma notificação global só para um público (colecionadores ativos ou vendedores) e escolher os canais para não incomodar quem não é o alvo.++ |
| Exportar Log de Auditoria | Como Administrador eu quero baixar em arquivo os registros filtrados do log de auditoria para guardar ou analisar fora da plataforma.++ |
| Ordenar Categorias Padrão | Como Administrador eu quero definir a ordem das categorias padrão e fixar uma no topo para controlar o que aparece primeiro no menu e na vitrine.++ |
| Duplicar Carta | Como Administrador eu quero criar uma carta a partir de outra já cadastrada para não digitar de novo os dados em comum.++ |
| Salvar Rascunho de Carta | Como Administrador eu quero salvar uma carta incompleta como rascunho, fora do catálogo, para terminar o cadastro depois.++ |
| Consultar Histórico de Relatórios | Como Administrador eu quero ver os relatórios exportados recentemente e baixar de novo um arquivo já gerado para não precisar exportar outra vez.++ |
