| Nome do Caso de Uso | Entrar em Contato |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso entrar em contato com o vendedor para esclarecer dúvidas ou negociar informações sobre uma carta anunciada. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e visualizando um anúncio ativo. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa os detalhes do anúncio. |  |
| 2. O cliente seleciona a opção “Entrar em contato”. |  |
| 3. O cliente digita e envia uma mensagem ao vendedor. |  |
|  | 4. O sistema identifica o vendedor responsável pelo anúncio. |
|  | 5. O sistema cria ou abre uma conversa entre o cliente e o vendedor. |
|  | 6. O sistema envia a mensagem. |
|  | 7. O sistema notifica o vendedor sobre a nova mensagem. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso o vendedor não esteja disponível para contato, o sistema informa que não foi possível iniciar a conversa. |
|  | 2. Caso o cliente tenha bloqueado ou sido bloqueado pelo vendedor, o sistema impede o envio da mensagem. |
