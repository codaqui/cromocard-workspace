| Nome do Caso de Uso | Visualizar Anúncios Ativos |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso visualizar os anúncios ativos para acompanhar as cartas disponíveis para compra no marketplace. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e possuir acesso ao painel da plataforma. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa o Dashboard. |  |
| 2. O cliente seleciona a seção “Anúncios Ativos”. |  |
|  | 3. O sistema busca os anúncios ativos relacionados ao cliente. |
|  | 4. O sistema exibe a listagem dos anúncios encontrados. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso não existam anúncios ativos disponíveis, o sistema exibe a mensagem: “Não existem anúncios ativos no momento.” |
