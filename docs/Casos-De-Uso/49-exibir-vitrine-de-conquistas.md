| Nome do Caso de Uso | Exibir Vitrine de Conquistas |
|---|---|
| Finalidade/Objetivo | Permitir que o usuário visualize suas conquistas obtidas na plataforma, apresentando seu progresso e realizações de forma organizada em seu perfil. |
| Atores | Cliente |
| Pré Condições | O usuário deve estar autenticado e possuir um perfil cadastrado. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O usuário acessa seu perfil. |  |
|  | 2. O sistema identifica as conquistas obtidas pelo usuário. |
|  | 3. O sistema apresenta a vitrine de conquistas no perfil. |
| 4. O usuário seleciona uma conquista. |  |
|  | 5. O sistema exibe os detalhes da conquista selecionada. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso o usuário ainda não possua conquistas, o sistema exibe a mensagem "Nenhuma conquista obtida". |
|  | 2. Caso uma conquista não esteja mais disponível, o sistema informa que os detalhes não podem ser exibidos. |
