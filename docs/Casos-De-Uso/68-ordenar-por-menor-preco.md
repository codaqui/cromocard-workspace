| Nome do Caso de Uso | Ordenar por Menor Preço |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso ordenar os anúncios por menor preço para encontrar as opções mais acessíveis. |
| Atores | Visitante, Cliente |
| Pré Condições | O ator deve estar no Explorar marketplace ou na lista de anúncios do perfil da carta. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O ator acessa o Explorar marketplace ou o perfil da carta. |  |
| 2. O ator seleciona a opção “Ordenar por menor preço”. |  |
|  | 3. O sistema organiza os anúncios em ordem crescente de preço. |
|  | 4. O sistema atualiza a listagem com os anúncios ordenados. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso não existam anúncios disponíveis, o sistema mostra "Nenhum anúncio encontrado". |
