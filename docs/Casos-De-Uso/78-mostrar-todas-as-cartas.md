| Nome do Caso de Uso | Mostrar Todas as Cartas |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso visualizar todas as cartas disponíveis na plataforma para explorar o catálogo e encontrar cartas de interesse. |
| Atores | Cliente |
| Pré Condições | O cliente deve acessar a seção de marketplace ou catálogo. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa a seção de cartas. |  |
|  | 2. O sistema busca as cartas cadastradas e disponíveis na plataforma. |
|  | 3. O sistema exibe a listagem de cartas. |
|  | 4. O sistema disponibiliza opções de busca, filtros e ordenação. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso não existam cartas cadastradas, o sistema informa que não existem cartas disponíveis. |
