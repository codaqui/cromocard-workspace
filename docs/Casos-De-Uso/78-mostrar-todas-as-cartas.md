| Nome do Caso de Uso | Mostrar Todas as Cartas |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso visualizar todas as cartas anunciadas no marketplace para encontrar cartas de interesse. |
| Atores | Visitante, Cliente |
| Pré Condições | Nenhuma. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O ator seleciona "Marketplace" no menu lateral ou "Explorar o marketplace" na Home. |  |
|  | 2. O sistema apresenta o Explorar marketplace com os anúncios ativos (carta, coleção, condição, preço e vendedor), 8 por vez, com "Carregar mais cartas", e o total de anúncios encontrados. |
|  | 3. O sistema disponibiliza os filtros por categoria (as categorias padrão), por condição (Mint, Near Mint, Ótimo, Bom e Regular) e por faixa de preço, e a ordenação por mais recentes (padrão), menor preço ou maior preço. |
| 4. O ator aplica filtros ou muda a ordenação. |  |
|  | 5. O sistema atualiza a lista e mostra os filtros aplicados, cada um com a opção de removê-lo. |
| 6. O ator seleciona um anúncio. |  |
|  | 7. O sistema abre o detalhe do anúncio. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso nenhum anúncio combine com os filtros, o sistema mostra "Nenhum anúncio encontrado" e a opção "Limpar filtros". |
