| Nome do Caso de Uso | Visualizar Informações da Carta |
|---|---|
| Finalidade/Objetivo | Permitir que o visitante ou o cliente visualize as informações da carta para conhecer suas características e identificação. |
| Atores | Visitante, Cliente |
| Pré Condições | O ator deve estar no perfil da carta (Visualizar Detalhes). |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa a seção de informações da carta na tela de detalhes. |  |
|  | 2. O sistema apresenta os dados de identificação da carta (nome, número, coleção, categoria, raridade e idioma). A carta do catálogo não tem condição: a condição é de cada anúncio. |
| 3. O cliente consulta as informações apresentadas. |  |
